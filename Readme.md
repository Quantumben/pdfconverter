# 📄 PDF to DOCX Converter (Django + Tailwind)

A simple Django web application that allows users to **upload PDF files**, **convert them to DOCX** using the [`pdf2docx`](https://pypi.org/project/pdf2docx/) library, and saves the original PDF in the database for admin review. Styled using **Tailwind CSS**.

---

## 🚀 Features

- Upload PDF files via a simple web form
- Convert PDF to DOCX using `pdf2docx`
- Save original PDF file to the database
- Admin panel to view uploaded files
- Clean and responsive UI using Tailwind CSS

---

## 🧰 Requirements

- Python 3.8+
- Django 4.x or 5.x
- pdf2docx
